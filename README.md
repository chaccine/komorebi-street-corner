# 晴间街角

树根穿过柏油路，常春藤爬上旧喫茶店的屋檐。拖动这个三维微缩街角，看看街道另一面的风景。细雨落进水洼，漾开一圈圈波纹。喫茶店檐边的水珠慢慢聚起，滴落在石板上。

[打开晴间街角](https://chaccine.github.io/komorebi-street-corner/)

第一次点按或拖动街角后就能听见细雨。把茶铺的橙色遮阳棚放大到画面中央，可以听见雨打棚布、檐滴落在石板上。将视角移向水洼，滴答声会渐渐清楚。

- 点樟树吹起一阵风。跟着一片落叶，看它落入路面的水洼，推开两圈涟漪。
- 点红色售货机，等一瓶波子汽水滚到人行道上。
- 点喫茶店切换午后与黄昏。天光渐暗后，楼上窗户和橱窗会先后亮起。再点一次回到午后。
- 直接点水面，涟漪就从指尖落下的位置向外扩散。

拉近茶铺的柜台，可以看到一台木壳收音机。点左半边的拨片开关全部声音，点右半边的旋钮依次选择仅雨声、雨和风、雨和鸟鸣、雨加风声与鸟鸣。M 键静音或恢复，B 键切换背景音。本浏览器会记住这两项设置。

拖拽旋转，按住鼠标右键拖动可平移。滚轮以鼠标所在位置为中心缩放，手机上用双指捏合，以两指中点为中心缩放。双击场景回到初始视角。

用键盘时，按 Tab 聚焦场景。方向键旋转，Shift 加方向键平移，加减号缩放，Home 复位。数字 1、2、3、4 依次触发樟树、售货机、喫茶店和水洼。
